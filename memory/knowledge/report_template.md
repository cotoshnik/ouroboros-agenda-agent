# Шаблон аналитической справки дежурной смены

Используется инструментами `build_report_draft` / `export_report_docx`.
Изменение шаблона — только через ревью человека (см. `../../safety/BIBLE.md`, P4).

```markdown
# Аналитическая справка дежурной смены — ЧЕРНОВИК

Дата формирования: <ГГГГ-ММ-ДД>
Сформировано автономным агентом agenda_briefing_agent; требует верификации аналитиком.

## 1. Базовый блок (обязательные показатели)
<все 49 показателей карты; отсутствующие — «— нет данных —»>

## 2. Динамический блок (включён по наличию фактических данных)
<показатели динамического блока с фактическими значениями за дату;
при отсутствии — явная фраза об отсутствии данных>

## 3. Сигналы для внимания аналитика
<показатели, сработавшие по пороговым правилам HOT_RULES, с пояснением>

## 4. Полнота данных
<отчёт check_completeness: собрано N/49, перечень недостающих>

---
Черновик. Выводы и интерпретация — за аналитиком (human-in-the-loop).
```

## Правила наполнения

1. Базовый блок — всегда целиком, даже с пропусками (пропуск ≠ удаление
   строки, а пометка «— нет данных —»).
2. Динамический блок — только по факту поступления данных.
3. Пороговые правила для раздела 3 заданы в `mcp/server.py` (`HOT_RULES`);
   их изменение — ревью человека.
4. Заголовок всегда содержит пометку «ЧЕРНОВИК» до верификации аналитиком.
5. Справка содержит ТОЛЬКО фактические значения за дату — без новостей,
   внешних ссылок и комментариев модели.

## Презентация (PPTX)

Отдельный артефакт: `export_report_pptx` / `export_report` по шаблону
пользователя. Содержит только отобранные analyst_agent и провалидированные
сервером показатели (см. `SKILL.md`, раздел 6): на каждом содержательном
слайде — название показателя, значение, единица измерения и дата.
Полнота данных выносится на финальный слайд. Пометка «ЧЕРНОВИК»
сохраняется до верификации.
